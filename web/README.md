# web —— Web 查看器（前端）

Vue 3 + Vite + **Element Plus**（表格/标签/分页/布局）+ **ECharts**（统计页图表）；
时间线详情页的瀑布条为轻量自绘（CSS/SVG，属布局元素而非图表，M1 决策 D-03/D-04）。

## 三视图（AT-DES-001 §6）

| 视图 | 路由 | 内容 |
|------|------|------|
| 列表页 | `/` | 时间/名称/状态/步数/Token/耗时；过滤 + 排序 + 分页 |
| 时间线详情 | `/traces/:id` | 上半区瀑布图（失败标红），下半区选中事件详情 |
| 统计总览 | `/stats` | 指标卡 + 失败类型分布 + 趋势图 |

## 初始化计划

Sprint 1 垂直切片：`npm create vite@latest` 初始化 + 列表页只读版（对接
`agenttrace seed` 造数与 `GET /api/traces`）；M3 补全详情页与统计页。
